# 📱 Como Testar o Sistema de Triagem — Terra Fértil Jardins

> **Para quem vai testar:** Siga os passos abaixo com calma. Não é necessário instalar nada especial.

---

## O que você vai precisar

- Um computador com **Windows** (7, 10 ou 11)
- **Python** instalado (veja o Passo 1)
- O arquivo `.zip` com os arquivos do sistema

---

## Passo 1 — Instalar o Python (só na primeira vez)

> Se já tiver Python instalado, pule para o Passo 2.

1. Acesse: **https://www.python.org/downloads/**
2. Clique no botão amarelo grande **"Download Python"**
3. Abra o arquivo baixado
4. ⚠️ **IMPORTANTE:** Antes de clicar em "Install Now", marque a caixinha **"Add Python to PATH"** na parte de baixo da tela
5. Clique em **"Install Now"** e aguarde
6. Quando terminar, clique em **"Close"**

---

## Passo 2 — Baixar o Sistema

1. Clique no link que foi enviado para você
2. Você verá uma página no GitHub com um arquivo chamado `TerraFertil_Triagem_CodigoFonte.zip`
3. Clique no arquivo para baixá-lo
4. Aguarde o download terminar

---

## Passo 3 — Extrair os Arquivos

1. Abra a pasta **Downloads** no seu computador
2. Clique com o **botão direito** no arquivo `TerraFertil_Triagem_CodigoFonte.zip`
3. Clique em **"Extrair tudo..."**
4. Escolha uma pasta fácil de encontrar (ex: **Área de Trabalho** ou **Documentos**)
5. Clique em **"Extrair"**
6. Uma nova pasta chamada `TerraFertil_Triagem_CodigoFonte` aparecerá

---

## Passo 4 — Iniciar o Sistema

1. Abra a pasta `TerraFertil_Triagem_CodigoFonte`
2. Procure o arquivo chamado **`Iniciar_Triagem.bat`**
3. Dê **dois cliques** nele

> Se aparecer um aviso do Windows dizendo "O Windows protegeu seu computador":
> - Clique em **"Mais informações"**
> - Clique em **"Executar mesmo assim"**

4. Uma **janela preta** vai abrir — isso é normal, não feche!
5. Aguarde alguns segundos — o **navegador de internet** abrirá automaticamente com o sistema

---

## Passo 5 — Usar o Sistema

O sistema abrirá mostrando **duas telas de celular** lado a lado:

| Tela da Esquerda | Tela da Direita |
|---|---|
| **App do Jardineiro** | **App da Gestão** |
| Simula o que o prestador de serviço vê | Simula o que o avaliador da empresa vê |

### O que você pode fazer:

**Pelo App do Jardineiro (esquerda):**
- Preencher o cadastro com dados pessoais
- Enviar documentos (simulado)
- Consultar o status da candidatura

**Pelo App da Gestão (direita):**
- Ver todos os candidatos cadastrados
- Analisar o dossiê de cada candidato
- Aprovar, reprovar ou pedir reenvio de documentos

---

## Passo 6 — Encerrar o Sistema

1. Para parar o sistema, **feche a janela preta** que ficou aberta
2. Ou clique nela e pressione as teclas **Ctrl + C** juntas

---

## ❓ Problemas comuns

**"O Python não foi encontrado" ou "py não é reconhecido"**
→ Refaça o Passo 1 com atenção para marcar "Add Python to PATH"

**A janela preta abre e fecha rapidamente**
→ Clique com o botão direito no arquivo `Iniciar_Triagem.bat` → "Executar como administrador"

**O navegador não abriu automaticamente**
→ Abra o navegador manualmente e acesse: `http://127.0.0.1:5000`
